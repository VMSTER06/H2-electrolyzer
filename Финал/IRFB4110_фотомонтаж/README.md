# Фотоинструкция IRFB4110PBF

Уточнение интерфейса: сами 89 шагов, их идентификаторы и порядок не изменены. В крупном шаге область выводов увеличена, рядом есть миниатюра целого корпуса; красный контур отмечает металл для пайки, а номер вынесен рядом. Для резистора первый выбранный конец назначается «1», оставшийся — «2», без ложного указания на полярность.

Режим «Все связи этого элемента» теперь показывает только выбранную деталь и непосредственные соединения из перечня монтажа, включая оба конца элемента. Например, для R5 видны Q1 и обе связи R5 с G/S; для R1 — драйвер U1, R1 и Q1. Остальные детали скрыты только в этом режиме. «Абсолютно вся схема» возвращает все 46 компонентов. Общая сеть GND не разворачивается рекурсивно во всю схему.

Актуальный просмотрщик: `../IRFB4110_сборка_поэтапно.html`. Есть три режима: крупный текущий шаг с двумя местами пайки; текущий элемент на полной схеме; вся схема без скрытия компонентов. В полном режиме карточка шага убирается, а кнопка возврата к текущему шагу сохраняет позицию.

89 шагов включают подготовку, все 86 ранее проверенных соединений и заключительную проверку. Они сгруппированы по деталям/узлам. Переход вперёд не отмечает физическую работу автоматически; отметка «Этот шаг выполнен» и текущая позиция сохраняются локально в браузере, если хранилище доступно.

`make-staged-guide.cjs` собирает автономный HTML из проверенного SVG и `overall-connections.json`, встраивая `staged-interface.js` и `staged-interface.css`. Просмотр не требует Node.js. `make-overall-guide.cjs` теперь автоматически вызывает этот генератор после пересборки схемы. Для изменения только интерфейса достаточно запустить `node .\make-staged-guide.cjs`.

Крупный шаг использует те же фото, координаты выводов и обозначения из общей схемы; положение деталей и маршрут одного провода упрощены. Топология силовой схемы и прошивка не изменены. Экспорт из любого режима всегда сохраняет всю общую схему, а не текущий фрагмент.

Текущая версия от 25.10.2026: `../IRFB4110_сборка_поэтапно.html` — инструкция с вкладками «Сборка и схема» и «Закупка». Все фото встроены, подключения к интернету для просмотра не нужны.

`purchase-tab.cjs` добавляет закупку в HTML из таблиц `../IRFB4110_итоговая_закупка_и_подключение.md`: 38 позиций для сборки и 5 необязательных позиций инструментов. Совпадающие номиналы объединяются с сохранением обозначений: 10 кОм — 5 шт., 100 нФ — 2 шт. Ссылки поиска явно отличаются от сохранённых карточек. Подытог 46,90 BYN относится только к восьми позициям с ценами из подбора от 23.10.2026; остальные цены не проверены. Закупка без термопасты и прокладок.

Отметки «Есть / куплено» сохраняются локально в браузере под ключом `irfb4110-purchases-v1`. Отметки и порядок 89 шагов сборки сохранены отдельно без изменений. `#zakupka` открывает вкладку закупки напрямую. Генератор `make-staged-guide.cjs` обновляет только `../IRFB4110_сборка_поэтапно.html` и `purchase-items.json`. На рабочем столе находится ссылка на этот файл, отдельной HTML-копии нет. Проверены вкладки, клавиатура, количества, сохранение покупок и текущего шага, мобильная ширина и отсутствие ошибок JavaScript.

`../IRFB4110_общая_схема_пайки.png` — полная картинка 4000 × 2550, экспортированная из самого просмотрщика. Редактируемая версия — одноимённый SVG. `overall-connections.json` содержит 46 компонентов, узлы, маршруты проводов и 86 инструкций между физическими выводами. При выборе провода подсвечивается полный путь между двумя реальными выводами, а не только участок до промежуточной точки.

Для регенерации текущей общей схемы:

```powershell
node .\make-overall-guide.cjs
```

Генератор проверяет количество компонентов, соответствие цепей концам проводов и связность всех сетей. Это проверка проекта соединений, не испытание физической сборки. Просмотрщик проверен в Chromium/Edge: подсветка, автоматическое увеличение, сброс, мобильная ширина и скачивание SVG/PNG. Прошивка устройства не изменялась.
