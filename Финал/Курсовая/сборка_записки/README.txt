Сборка пояснительной записки из спецификации (Word COM, PowerShell 5.1).

1. pz_spec.txt  - весь текст записки с разметкой (#H1/#H2 заголовки, #P абзац, #L пункт списка,
                  #F формула<TAB>(номер), #W/#W2 расшифровка "где", #T/#R/#TEND таблица,
                  #FIG файл<TAB>подпись[<TAB>ширина_мм], #LISTING путь к файлу кода, #APP буква|вид|название).
                  Внутри текста: _{индекс}, ^{степень}, *{курсив}.
2. build_pz.ps1 - собирает .docx. Запуск (скрипт нужно сохранить с BOM UTF-8, если править Cyrillic):
   powershell -ExecutionPolicy Bypass -File build_pz.ps1 -Spec pz_spec.txt -Out out.docx -FigDir рисунки
   В конце печатает страницы заголовков; нумерация страниц в документе начинается с 3
   (титульный лист и задание печатаются отдельно).
3. drawfig.ps1  - рисует схемы из JSON (мм, 300 dpi): powershell -File drawfig.ps1 -Spec рисунки/fig_struct.json -Out рисунки/fig_2_1.png
4. measure.ps1  - показывает, на какой странице и высоте заканчивается каждый раздел (для подгонки объёма).
5. export_pdf.ps1 - экспорт .docx в PDF через Word.
Условие объёма: страница ЗАКЛЮЧЕНИЯ - страница ВВЕДЕНИЯ + 1 = 35 (сейчас 39 - 5 + 1 = 35).
