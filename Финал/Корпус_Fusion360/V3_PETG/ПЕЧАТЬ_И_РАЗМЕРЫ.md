# H2 PRO V3 — K1 Max первой ревизии, НИТ PETG, сопло 0,6 мм

V3 уточняет существующую модель по опубликованным чертежам и предусматривает печатные зазоры. CAD остаётся в номинальных миллиметрах. Интернет подтверждает размеры конкретных серий, но не идентифицирует без маркировки ваши экземпляры. Самодельные платы и их распайка остаются оценкой по фото.

Габарит корпуса 140×180×67 мм; с кнопками около 70,4 мм. Стенки и дно 3 мм. Плата LCD опущена, оставлен консервативный запас глубины рамки 12 мм над PCB и 0,8 мм до крышки. Геометрия рамки и I2C-переходника является ограничивающим габаритом, а не точной копией каждой детали.

## Посадки для PETG

- Крышка: боковой зазор направляющего бурта 0,5 мм на сторону.
- Проходные отверстия M3: Ø3,6 мм; головки крышки: Ø6,8 мм.
- Толкатели: Ø5,5 в направляющей Ø6,3, радиальный зазор 0,4 мм. Зазор до ненажатой кнопки типоразмера 4,3 мм — 0,35 мм.
- Крепление LCD: M2×8 с шайбами наружным диаметром до 5 мм. Пилоты Ø1,7, глубина около 7 мм; подготовить резьбу/прочистить пробное отверстие. M3 не рассчитан на PCB с отверстиями Ø2,5.
- Винты крышки M3×10, накладки M3×10, держателя M3×8, прижимов плат M3×8. Реальную длину сверить по шайбам, не упирать винты в дно пилотов.
- Регулировочный слот релейного прижима 8×3,6 мм. Ослабив винты, подвести прижимы к свободным краям платы; не давить на реле, клеммы и пайку. Полная совместимость со всеми вариантами расположения компонентов не подтверждена.
- Символы кнопок выполнены 1/2/3 полосками шириной 0,8 мм — более подходящая геометрия для сопла 0,6, чем тонкие цифры V2.

## Усадка: два разных комплекта STL

У НИТ в доступных открытых карточках и разделе документов не найден численный коэффициент усадки именно вашей катушки. Нет оснований называть 0,3% измеренным свойством НИТ. Помимо усадки на размеры влияют подача материала, первый слой и печать отверстий.

1. **STL_print_nominal** — модель с монтажными зазорами, без масштабирования. Все детали уже ориентированы для печати и опущены на стол. Это исходный комплект для откалиброванного профиля.
2. **STL_print_trial_XY_100.301** — пробная компенсация предполагаемой усадки XY на 0,3%. Масштаб XY = 1/(1−0,003) = 100,3009%; Z = 100%. Это вариант для проверки, а не обещание точной посадки. Размер основания в файле примерно 140,421×180,542 мм.

Использовать только один способ: либо компенсацию в слайсере с номинальными файлами, либо уже увеличенные файлы с масштабом слайсера 100% и отключённой дополнительной компенсацией усадки. Не применять оба способа одновременно. Увеличивать электронику и всю CAD-сборку не нужно.

### Сначала два коротких теста

Печатать `test_XY_100_40_holes.stl` без компенсации, в масштабе 100%, после калибровки подачи и с теми же настройками, что корпус. Остудить до комнатной температуры. Измерить наружные плечи 100 мм по X и Y выше наплыва первого слоя. Дополнительные плечи 40 мм помогают заметить постоянную ошибку контура. Если ошибка примерно одинакова в миллиметрах на 40 и 100 мм, сначала исправить контур/подачу; масштабирование её корректно не устранит.

Проверить отверстия: слева направо вдоль длинного горизонтального плеча Ø3,2 / 3,4 / 3,6 / 6,3. Последнее проверяется толкателем корпуса. Не выбирать компенсацию всей детали только по диаметру маленького отверстия.

После устранения постоянной ошибки, при преобладающей пропорциональной погрешности можно рассчитать отдельный масштаб: X = 100/измеренный_X, Y = 100/измеренный_Y. Например, 99,70 мм вместо 100 мм даёт 100,3009%. Скрипт `prepare_print.py` создаёт новые файлы из исходных, не накапливая масштабирование:

```text
python prepare_print.py --measured-x 99.70 --measured-y 99.70 --output STL_print_measured
```

Второй образец `test_LCD_93x55.stl` — тонкая пластина с отверстиями по шагу 93×55. Проверить на своём LCD до печати большой крышки. Затем пробно напечатать накладку, держатель и один толкатель: это подтверждает оценённую посадку самодельной платы и высоту кнопок.

## Начальные настройки печати

Это предложенная отправная точка для качества на K1 Max первой ревизии, а не проверенный профиль НИТ. Указания на вашей катушке имеют приоритет. Использовать профиль именно K1 Max с установленным соплом 0,6 мм; стартовый G-code штатного профиля принтера не заменять.

| Настройка | Стартовое значение |
|---|---|
| Слой / первый слой | 0,24 / 0,24 мм |
| Ширина линии | 0,66 мм |
| Периметры | 5; тонкие стенки — переменная ширина линии |
| Верх / низ | не менее 6 слоёв |
| Заполнение | 20–25% gyroid |
| Сопло | 245 °C; первый слой 250 °C, уточнить температурным тестом |
| Стол | 80 °C, уточнить по покрытию и катушке |
| Максимальный объёмный поток | 8 мм³/с до проверки подачи |
| Наружная стенка | 30–35 мм/с |
| Внутренние / заполнение | до 50 мм/с, с ограничением потока |
| Первый слой | 20 мм/с |
| Обдув детали | сначала 0%, далее ориентировочно 30–50% |
| Боковой дополнительный обдув | 0% как отправная точка, чтобы не охлаждать корпус с одной стороны |
| Кайма основания | 5–8 мм при необходимости |

При 0,66×0,24 мм и 50 мм/с расчётный поток около 7,92 мм³/с. Рекламная скорость принтера не является скоростью этого профиля. Flow ratio и pressure advance зависят от конкретного филамента и экструдера; готовые «точные» значения не выдуманы. Материал должен быть сухим.

Основание печатать дном вниз, крышку и накладку наружной стороной вниз, держатель и прижимы плоской стороной вниз. В подготовленных STL это уже сделано. Толкатели ориентированы нажимным торцом на стол: контролировать маленький свес удерживающего буртика, при необходимости дать локальную поддержку. Внутри отверстий и пилотов поддержки не ставить. Посадочный бурт и направляющие очистить от нитей.

## Сборка и ограничения

Последовательность: платы в основании → LCD в крышке → толкатели в накладку → плата кнопок в держатель → держатель к накладке → накладка к крышке → подключение шлейфов → крышка. Плата кнопок фиксируется через передние прорези держателя по свободному краю, не поверх кнопок/LED. Порядок функций сверить с распайкой.

Пилоты рассчитаны на резьбу в пластике, термовставки не предусмотрены. Внешний доступ к USB и установленному на самодельной плате выключателю не добавлен без привязки к фактическим разъёмам. Проверка CAD относится к макетам габаритов, а не каждой пайке и проводу. Физическая сборка и печать ещё не выполнялись.
