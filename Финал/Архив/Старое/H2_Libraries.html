⚡ H2 PRO v4.3 — Библиотеки Arduino IDE

Мозг v4.3 · Пульт v4.4 · ESP32 DevKit v1 (WROOM-32D)
⓪ Сначала: добавить поддержку ESP32 в Arduino IDE

Arduino IDE не умеет работать с ESP32 по умолчанию. Нужно один раз добавить URL платы.

https://espressif.github.io/arduino-esp32/package_esp32_index.json
  1. Arduino IDE → File → Preferences
  2. В поле Additional Boards Manager URLs вставить URL выше
  3. Tools → Board → Boards Manager
  4. Найти "esp32", установить пакет от Espressif Systems
  5. Tools → Board → esp32 → выбрать DOIT ESP32 DEVKIT V1
GitHub espressif/arduino-esp32
Обязательные — устанавливать через Library Manager (Tools → Manage Libraries)
ОБЯЗАТЕЛЬНАЯ Library Manager
RF24
TMRh20, Avamander
Драйвер для радиомодулей NRF24L01+. Используется на мозге и пульте для двусторонней беспроводной связи 2 Мбит/с. Без этой библиотеки компиляция невозможна.
Искать в Library Manager: RF24 → автор TMRh20
GitHub ZIP
ОБЯЗАТЕЛЬНАЯ Library Manager
AsyncTCP
ESP32Async (me-no-dev)
Асинхронная TCP-библиотека для ESP32. Зависимость для ESPAsyncWebServer — без неё веб-сервер не скомпилируется. Устанавливать строго ESP32-версию (не ESPAsyncTCP, та для ESP8266).
Искать в Library Manager: AsyncTCP → автор ESP32Async
GitHub ZIP
ОБЯЗАТЕЛЬНАЯ Library Manager
ESPAsyncWebServer
ESP32Async / lacamera
Асинхронный HTTP-сервер для ESP32. Обслуживает веб-интерфейс на 192.168.4.1 — страницу управления, эндпоинты /status, /cmd, /setpressure, /sethysteresis. Требует AsyncTCP (см. выше).
Искать в Library Manager: ESP Async WebServer → автор lacamera
GitHub ZIP
ОБЯЗАТЕЛЬНАЯ Library Manager
Adafruit SSD1306
Adafruit
Драйвер OLED-дисплея 128×64 на контроллере SSD1306. Используется на мозге и пульте. При установке IDE предложит установить зависимости — нажать "Install All", чтобы автоматически поставились GFX и BusIO.
Искать в Library Manager: Adafruit SSD1306 → автор Adafruit
GitHub ZIP
ЗАВИСИМОСТЬ SSD1306 Library Manager
Adafruit GFX Library
Adafruit
Графическое ядро — линии, прямоугольники, текст, шрифты. Нужна для SSD1306. Обычно ставится автоматически при установке SSD1306 ("Install All"). Если не поставилась — установи вручную.
Искать в Library Manager: Adafruit GFX Library → автор Adafruit
GitHub ZIP
ЗАВИСИМОСТЬ GFX Library Manager
Adafruit BusIO
Adafruit
Абстракция I²C/SPI шин, нужна для GFX Library. Также обычно ставится автоматически. Если при компиляции ошибка про BusIO — установи вручную.
Искать в Library Manager: Adafruit BusIO → автор Adafruit
GitHub ZIP

WiFi.h
Espressif
Wi-Fi точка доступа AP для мозга (SSID: H2_PRO). Входит в ESP32 Arduino Core.
GitHub

Preferences.h
Espressif
NVS-хранилище (энергонезависимая память). Мозг v4.3 сохраняет в ней драйвер, гистерезис и целевое давление — настройки переживают перезагрузку.
GitHub
ВСТРОЕННАЯ
SPI.h
Arduino / Espressif
SPI-шина. Используется для связи ESP32 с модулем NRF24L01+ (VSPI: GPIO 18/19/23).
GitHub
ВСТРОЕННАЯ
Wire.h
Arduino / Espressif
I²C-шина. Используется для OLED (адрес 0x3C) и MPU6050 (адрес 0x68) на одной общей шине GPIO 21/22. Для MPU6050 отдельная библиотека не нужна — прямой I²C-доступ.
GitHub
ВСТРОЕННАЯ
math.h
Стандартная библиотека C
Математические функции: acos(), sqrtf(), roundf(). Используется для расчёта угла наклона TILT-защиты по формуле скалярного произведения.
Рекомендуемый порядок установки
1
Установить Arduino IDE 2.x → arduino.cc/en/software
2
File → Preferences → вставить URL ESP32 Boards Manager:
https://espressif.github.io/arduino-esp32/package_esp32_index.json
3
Tools → Board → Boards Manager → найти "esp32" → Install (Espressif Systems)
4
Tools → Manage Libraries → найти и установить RF24 (by TMRh20)
5
Там же установить AsyncTCP (by ESP32Async)
6
Там же установить ESP Async WebServer (by lacamera)
7
Там же установить Adafruit SSD1306 → при запросе нажать "Install All" (автоматически поставит GFX и BusIO)
8
Выбрать плату: Tools → Board → esp32 → DOIT ESP32 DEVKIT V1
9
Открыть H2_Brain_v4.ino или H2_Remote_v4.ino → Sketch → Verify/Compile (Ctrl+R) — должна скомпилироваться без ошибок
