Как читать · распиновка Arduino Nano

сначала прочитайте этот этап
Какие выводы Nano заняты
Правила
1Сначала впаяйте Arduino Nano в плату: две крайние точки по диагонали, выровнять, затем остальные выводы.
2Каждый этап — один модуль. Слева вывод модуля, справа — вывод Arduino Nano, к которому его вести.
3Цвет линии на схеме = цвет провода. Номер провода в кружке совпадает с таблицей этапа.
4«5V» и «GND» — общие линии: к ним сходятся провода питания всех модулей.
5Внешний провод: зачистить и залудить 3–4 мм, пропаять, на пайку — термоусадка.
6Паяльник 25–40 Вт, 1–2 секунды на точку, припой должен лечь блестящим конусом.
7После каждого этапа — проверка из последнего пункта. Ошибка, пропущенная рано, дорого стоит потом.

🔋 Питание: разъём USB Type-C (XP1)

2 провода
№Вывод модуляВывод NanoЧерезЦвет проводаЗаметка
1VBUS (+5 В)→5V—красныйлиния +5 В
2GND→GND—чёрныйобщий провод
Порядок действий
11 VBUS (+5 В) → 5V Nano (красный провод)
22 GND → GND Nano (чёрный провод)
3Все провода «+5 В» и «GND» следующих модулей соединяются с этими же линиями: удобно сделать две общие шины (лужёный провод) — +5 В и GND — и паять модули к ним.
✔Проверка: между 5V и GND Nano НЕТ короткого замыкания (не 0 Ом).
Используются только VBUS и GND, остальные выводы переходника свободны.

3VD1 «OK» зелёный, анод +→D8R1 220 Омзелёный
4VD2 «LOW» жёлтый, анод +→D10R2 220 Омжёлтый
5VD3 «GAS» красный, анод +→D9R3 220 Омкрасный
6VD4 «TEMP» красный, анод +→D12R4 220 Омтёмно-красный
7катоды − всех VD1–VD4→GND—чёрный
Порядок действий
13 VD1 «OK» зелёный, анод + → D8 Nano через R1 220 Ом (зелёный провод)
24 VD2 «LOW» жёлтый, анод + → D10 Nano через R2 220 Ом (жёлтый провод)
35 VD3 «GAS» красный, анод + → D9 Nano через R3 220 Ом (красный провод)
46 VD4 «TEMP» красный, анод + → D12 Nano через R4 220 Ом (тёмно-красный провод)
57 катоды − всех VD1–VD4 → GND Nano (чёрный провод)
6Анод — длинная ножка (+), катод — короткая (−).
7Резистор 220 Ом ставится между выводом Nano и анодом каждого светодиода.
8Провода от Nano к панели — МГТФ по 20 см, скрутить в жгут.
✔Проверка: мультиметр «диод»: красный щуп на вывод Nano, чёрный на GND — светодиод слабо светится.

№Вывод модуляВывод NanoЧерезЦвет проводаЗаметка

Порядок действий
112 GND → GND Nano (чёрный провод)

314 SDA → A4 Nano (розовый провод)
415 SCL → A5 Nano (фиолетовый провод)

✅ Проверка перед первым включением

всё устройство
Чек-лист
1Осмотр с лупой: нет капель припоя между соседними выводами Nano.
25V–GND: нет короткого замыкания (не 0 Ом).
3Прозвонить каждый провод по общей таблице ниже: вывод модуля ↔ вывод Nano.
4Первое включение — от USB-C (XP1), без прошивки. Между 5V и GND должно быть 4,7–5,2 В. Что-то греется или пахнет — сразу отключить.
5MQ-2 тёплый — это норма (внутри нагреватель), показания стабилизируются через 1–2 мин.
6Прошить gsm_control_lcd2004.ino. Пустой экран при горящей подсветке — покрутить подстроечник контраста на плате I²C; ничего — сменить адрес LCD_ADDR на 0x3F.
