# H2 PRO для Android

Локальное приложение для мозга H2 PRO. Работает через Wi-Fi `H2_PRO` и HTTP API прошивки по адресу `192.168.4.1`; интернет и учётная запись не нужны.

## Установка

1. Установить `app/build/outputs/apk/debug/app-debug.apk` на телефон Android 8.0 или новее. Это отладочный APK, подписанный локальным ключом сборки.
2. Подключить телефон к Wi-Fi `H2_PRO` (пароль указан в прошивке мозга).
3. Открыть приложение. Оно обнаружит Wi-Fi с адресом `192.168.4.x`, привяжет свои запросы к этой сети и начнёт читать `/status`.

## Возможности

Версия 1.1: интерфейс переработан в светлой и тёмной темах. Настройки приложения открываются шестерёнкой в правом верхнем углу. Доступны автоматическая системная тема, интервал обновления 1/2/5 секунд, точность давления, виброотклик и запрет выключения экрана. Выбор сохраняется локально. Есть переход в системные настройки Wi-Fi. Аппаратная кнопка «Назад» возвращает из настроек в прежний раздел, из других разделов — на обзор.

- Текущее и целевое давление, температура, состояние системы, блокировка, связь с пультом, наработка.
- Кнопки POWER, LOCK, короткая и полная продувка, ручной газ, репульсор, поджиг. Команды выполняются по одному нажатию без подтверждений.
- Настройка цели давления, гистерезиса и выводного вентилятора.
- Выбор зуммера, громкости, сигналов тревоги и щелчков; прослушивание встроенных и сохранённых мелодий.
- Диагностика LCD2004/OLED, DS18B20, MPU6050, nRF24 и файловой системы.

Версия 1.3.0 — всё, что умеет веб-интерфейс мозга:

- «Обзор»: баннер тревог и предупреждений в порядке веб-интерфейса (наклон, давление, датчики, утечка, перегрев, приближение к аварии, бак не набирает, обслуживание, ресурс реле, таймер, калибровка MPU); окраска давления, перегрев, угол наклона, строка текущего процесса; цель давления ±0,5 и быстрые 1…6.
- «Управление»: команды блокируются по состоянию и подсвечиваются, пока идут; обнуление счётчика газа.
- «История» (новая вкладка): графики давления и температуры за час/день/неделю, максимумы, экспорт CSV/JSON, импорт, очистка.
- «Звук»: мелодии при загрузке и при включении, индикатор «играет», слоты и свободное место, прослушивание на телефоне, удаление, импорт MIDI/RTTTL/аудио с подготовкой под зуммер и загрузкой в мозг.
- «Статус»: «Что проверить» по всем модулям, циклы реле и RF-перескоки со сбросом, сброс наработки, очистка журнала; в разделе «Сервис» — калибровка датчика давления и OTA-обновление прошивки.
- Аварийные «Сброс давления», «Блокировка» и «Заглушить» не ждут других запросов; «Сброс давления» отправляется и без связи (ответит телефон). Одна неудача опроса не сбрасывает экран — показания помечаются устаревшими.
- Интерфейс после UI-ревью: при аварии нужное действие («Сброс давления» или «Разблокировать») и «Заглушить» стоят прямо в баннере на первом экране; авария и предупреждение различаются цветом, значком и словами «Авария» / «Внимание»; ошибки говорят, что делать, и держатся до касания; «Обслужено» спрашивает подтверждение; видимый фокус везде; вёрстка выдерживает системный шрифт до 200 %.
- Фоновое наблюдение держит процессор, пока телефон в сети H2_PRO (проверка каждые 10 с при погасшем экране), сообщения о связи идут в отдельный канал, уведомления — с монохромной иконкой.

Мост Java — один метод `Brain.request(id, method, path, type, bodyBase64)` с белым списком путей и проверкой диапазонов; опрос, команды и загрузки идут тремя отдельными очередями.

Приложение само не включает электролизёр, поджиг или клапан при запуске. Кнопки отправляют запросы на действующие эндпоинты прошивки. Ответ HTTP `OK` означает приём команды; окончательное состояние показывается после следующего чтения `/status`.

## Сборка

Открыть папку `H2_Android_App` в Android Studio и выполнить `assembleDebug` либо запустить `gradlew.bat assembleDebug`. Проект использует Java 17, Android SDK 34, Gradle 8.9 и Android Gradle Plugin 8.2.2. Внешних библиотек приложения нет. `local.properties` содержит путь к SDK на компьютере автора и при переносе проекта должен указывать на SDK другого компьютера.

## Исходники

- `app/src/main/java/by/h2pro/control/MainActivity.java` — привязка к Wi-Fi мозга и HTTP-мост.
- `app/src/main/assets/index.html` — экраны и SVG-иконки.
- `app/src/main/assets/style.css` — адаптивное оформление и обе темы.
- `app/src/main/assets/app.js` — состояние, команды, настройки и обновление показаний.
- API взят из `../H2_Brain_v5/H2_Brain_v5.ino` и `../H2_Brain_v5/h2_sound.h`.
