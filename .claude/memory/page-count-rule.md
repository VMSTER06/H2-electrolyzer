Правило преподавателя по объёму: (стр. Заключения) − (стр. Введения) + 1 ≥ 35. Больше 35 — допустимо (пользователь подтвердил 28.10.2026, при 38 страницах).

**Why:** раньше подгоняли ровно под 35 и резали текст; пользователь уточнил, что нужно «не меньше 35».

**How to apply:** не сокращать текст ради ровно 35; проверять только, что объём не упал ниже 35.
