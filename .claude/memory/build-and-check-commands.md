Курсовой H2 (Финал/Курсовая/сборка_записки), с 31.10.2026:
- `bash make_all.sh [_build/cur]` — листинг без веба → схемы → записки полная и КП3 → Д1 с верным числом страниц → PDF листов задания → раскладка по папкам и zip КП3 → проверка. ~15–20 мин (Word), запускать в фоне.
- `py -3 check_all.py [папка_сборки]` — только проверка (≈10 с): СТП (исходник, docx, вёрстка PDF: заполненность, висячие заголовки), правила преподавателя, обозначения текст↔Э3↔ПЭ3↔Э2, Э1/Э2, листинг без веба, лист задания, комплект/zip. Выводит только проблемы.
- Листинг (прил. Е) берётся из очищенной копии `сборка_записки/листинг` (make_listing_src.py), не из настоящей прошивки.
- arduino-cli: обычный конфиг не видит ядро ESP32 (папка packages «перемещена»); работает конфиг scratchpad/a15/cli.yaml с junction'ами на packages/{arduino,builtin,esp32}, запуск без песочницы.

**How to apply:** после любой правки — сначала `check_all.py`, а не ручной осмотр; для пересборки — `make_all.sh`. Это экономит токены (просьба пользователя). Связано с [[page-count-rule]], [[assignment-power-wording]].
