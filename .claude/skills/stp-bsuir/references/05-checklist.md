# Чек-лист нормоконтроля по СТП 01–2024

Для каждого замечания указывай пункт СТП. Раздели замечания на три группы:
1. **Нарушение СТП**: требование выражено словами «должен», «не допускается» и т. п.
2. **Отклонение от рекомендации**: «рекомендуется», «как правило».
3. **Вопрос к руководителю**: то, что СТП не регулирует для данного типа работы, например дипломные нормы для курсового, литера, код классификатора, учёт страниц задания.

Проверяй по PDF: Word при сборке показывает устаревшие номера страниц и поля.

## Страница и текст (2.1, прил. Л)
- [ ] А4; поля 30/15/20/20 мм; текст на одной стороне листа.
- [ ] TNR 14 везде, включая таблицы, подписи, содержание и **номера страниц в содержании**; других шрифтов (Calibri, Aptos) в полях нет.
- [ ] Интервал точно 18 пт везде, включая ячейки таблиц и содержание; интервал до и после абзацев 0.
- [ ] Абзацный отступ 1,25 см задан стилем (не пробелами и не табуляцией); выравнивание по ширине.
- [ ] Переносы разрешены в тексте и отключены в заголовках, названиях таблиц и подписях рисунков.
- [ ] Номер страницы справа внизу, в 10 мм от края. На титульном листе, реферате и задании номера нет, но они учтены в счёте. Приложения входят в нумерацию, номер виден и на вставленных листах.

## Структура (1.2.5–1.2.19, 2.2)
- [ ] Порядок частей соответствует СТП или заданию.
- [ ] СОДЕРЖАНИЕ полужирным 14–16 пт по центру, затем пробельная строка. Отточие до номера страницы, уровни сдвинуты на 2 знака. Есть все разделы, подразделы и приложения, номера страниц актуальны.
- [ ] Ненумерованные заголовки ПРОПИСНЫЕ, полужирные, по центру, без отступа.
- [ ] Заголовки разделов «N ЗАГОЛОВОК», подразделов «N.M Заголовок»: полужирные, с абзацного отступа, без точки в конце, без подчёркивания и переносов; продолжение строки под первой буквой текста заголовка.
- [ ] Пробельная строка после заголовка, до и после подраздела. Раздел начинается с новой страницы. Заголовок не висит внизу страницы.
- [ ] Введение не более 2 страниц; у диплома последний абзац — об оригинальности.
- [ ] Заключение не более 1,5–2 страниц, в форме констатации («разработана», «показано»…), с конкретными данными.

## Язык и числа (2.3)
- [ ] Нет «мы получили», «мы нашли», «будем иметь», «получится».
- [ ] Перечисления оформлены правильно: «– …;» с отступа; сложные «1 …»; ссылочные «а)», «1)». Вводная фраза не обрывается на предлоге или союзе («состоит из:» — ошибка).
- [ ] В тексте «минус 40 °С», а не «–40 °С»; знаки %, №, >, = без чисел записаны словами.
- [ ] Числа 1–9 без единиц записаны словами. Нет «в 600 Вт». Используется «не более / не менее». Диапазон «от 2 до 20 км».
- [ ] Единицы СИ по ГОСТ 8.417–2002, после числа через пробел (как в образцах СТП: «600 Вт», «24 %»). Нет внесистемных единиц без пересчёта в СИ.
- [ ] Иностранные термины не используются, если есть русские равнозначные.

## Формулы (2.4)
- [ ] Каждая формула на отдельной строке по центру, отделена пробельными строками, номер «(N.M)» у правого края.
- [ ] Латиница курсивом, кириллица и греческие буквы прямо; русские индексы прямо.
- [ ] После формулы стоит знак препинания. «где» с новой строки без отступа и без двоеточия. Расшифрованы все ещё не пояснённые символы; расшифровки через тире, каждая заканчивается «;», единица в конце через запятую; перечень выровнен по символам.
- [ ] Единица не стоит в строке с буквенной формулой; при подстановке единица идёт после результата.
- [ ] Ссылки на формулы со словом: «формула (2.3)». У заимствованных формул есть ссылка на источник.

## Рисунки (2.5)
- [ ] На каждый рисунок есть ссылка, рисунок стоит после абзаца с первой ссылкой.
- [ ] Рисунок по центру, отделён от текста и подписи пробельными строками.
- [ ] Подпись «Рисунок N.M – Название» по центру, без точки, без переносов, единообразная. В приложениях — «Рисунок А.1».
- [ ] Обозначения объяснены либо в тексте, либо под рисунком, но не вперемешку.
- [ ] У иллюстраций в тексте нет рамок и штампов ЕСКД. Надписи на рисунках не мельче 2,5 мм.

## Таблицы (2.6)
- [ ] «Таблица N.M – Заголовок» над таблицей от её левой границы, без точки, без переносов, не шире таблицы.
- [ ] Пробельные строки до заголовка и после таблицы; между заголовком и таблицей пробельной строки нет.
- [ ] На каждую таблицу есть ссылка, таблица стоит после первой ссылки.
- [ ] Нет графы «№ п/п»; нет диагонального деления ячеек; нет сокращений («Кол-во», «Напр.», «Хар-ка»); головка в именительном падеже единственного числа с прописной; единица после наименования через запятую.
- [ ] Нет пустых ячеек (вместо них тире). Одинаковое число знаков после запятой в столбце; однородные числа выровнены по разрядам, разнородные — по центру.
- [ ] При переносе: «Продолжение таблицы N.M» и повтор головки или строки нумерации граф.
- [ ] Примечание внутри таблицы над нижней линией.

## Приложения (2.7)
- [ ] На каждое приложение есть ссылка в тексте; порядок приложений соответствует порядку ссылок; буквы без Ё, З, Й, О, Ч, Ъ, Ы, Ь.
- [ ] С новой страницы по центру: «ПРИЛОЖЕНИЕ А» / «(обязательное)» / заголовок.
- [ ] Приложения перечислены в содержании и входят в нумерацию страниц.
- [ ] Самостоятельные документы (листы схем, перечень элементов) вставлены с рамкой и штампом, ничего не обрезано.

## Источники (2.8)
- [ ] Заголовок «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ» по центру с новой страницы, перед приложениями.
- [ ] Ссылки [N] нумеруются по порядку первого упоминания, все источники процитированы. Точка после «]». Ссылка не переносится на новую строку отдельно от слова.
- [ ] Записи по ГОСТ 7.1–2003: «Фамилия, И. О. Название / И. О. Фамилия. – Город : Издательство, год. – N с.». Пробелы вокруг «:», «;», «/», «–». «Минск» полностью. У электронных ресурсов «[Электронный ресурс]. – Режим доступа : URL».
- [ ] Нет Wikipedia и других вики-ресурсов.

## Графические документы (раздел 3)
- [ ] Рамка: 20 мм слева, по 5 мм с остальных сторон, сплошная основная линия.
- [ ] Форма основной надписи соответствует документу: схема или чертёж — «а» 185×55 с «Масса» и «Масштаб»; текстовый документ — «б» 185×40; последующие листы — «в» 185×15. Размеры столбцов 7/10/23/15/10.
- [ ] Обозначение `ГУИР.XXXXXX.NNN Эk`, где XXXXXX — код по классификатору ЕСКД, а не код специальности. Для ЕСПД вместо него номер группы.
- [ ] Графа (1): «Наименование изделия» и под ним «Схема электрическая структурная». Графа (9): кафедра и группа. Графа «Лист» пуста у однолистового документа, «Листов» = 1. Литера по стадии, согласована с руководителем.
- [ ] Линии связи сплошные тонкие 0,3–0,4 мм, только горизонтальные и вертикальные, с минимумом изломов. Штриховые линии используются только для механической связи и экрана, штрихпунктирные — для выделения групп.
- [ ] Стрелки с развалом 60° (обрыв питания — 30°); размер стрелок одинаков на всех листах.
- [ ] Э1: прямоугольники с наименованиями (строчными с прописной), ход процесса слева направо. Для МП-системы функции МП выделены штрихпунктиром (3.17.1).
- [ ] Э2: у элементов есть позиционные обозначения с Э3 и типы; сокращения пояснены на поле; не более трёх толщин линий.
- [ ] Э3: изделие в отключённом состоянии; позиционные обозначения по ГОСТ 2.710 (табл. 3.21), нумерация сверху вниз и слева направо, справа от УГО или над ним; указаны входы и выходы и их параметры. Есть перечень элементов ПЭ3 (форма «б», группы по алфавиту кодов).
- [ ] Обозначения элементов согласованы в Э1, Э2, Э3, ПЭ3 и тексте ПЗ (DD — цифровая микросхема, DA — аналоговая, A — устройство или модуль).
- [ ] Шрифт надписей чертёжный (ГОСТ 2.304), единообразный; высота строчных букв не менее 2,5 мм.
- [ ] Схема алгоритма по ГОСТ 19.701: символы в пропорциях; терминаторы «Начало» и «Конец»; стрелки только против основного направления (вверх или влево); у решений подписаны исходы «Да»/«Нет».
