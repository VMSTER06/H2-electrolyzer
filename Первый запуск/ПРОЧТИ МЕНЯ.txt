ДЛЯ ЧЕГО ЭТА ПАПКА
  Здесь собрано всё, что нужно для работы с проектом на новом ноутбуке:
  драйвер платы, Arduino IDE, ESP32-ядро и библиотеки модулей. Просто
  скопируйте всю папку «Первый запуск» на новый ноут и запустите установщик.

═══════════════════════════════════════════════════════════════════════
КАК УСТАНОВИТЬ (1 действие)
═══════════════════════════════════════════════════════════════════════
  1. Дважды кликните файл:  «УСТАНОВИТЬ ВСЁ.bat»
  2. Появится окно «Контроль учётных записей (UAC)» — нажмите «Да»
     (права администратора нужны для установки драйвера).
  3. Дождитесь сообщения «ГОТОВО!». Можно закрывать окно.

  ⚠ Нужен ИНТЕРНЕТ — только для скачивания ESP32-ядра (~большой объём).
    Драйвер, Arduino IDE и библиотеки ставятся ОФЛАЙН из этой папки.

═══════════════════════════════════════════════════════════════════════
ЧТО УСТАНОВИТСЯ
═══════════════════════════════════════════════════════════════════════
  1) Драйвер CP210x (USB-чип платы ESP32)         — офлайн, drivers\CP210x
  2) Arduino IDE 2.3.10                            — офлайн, tools\
  3) ESP32-ядро (esp32:esp32)                      — из интернета
  4) Библиотеки модулей (офлайн, tools\libs):
       • RF24                  — радиомодуль nRF24L01+
       • Adafruit GFX + SSD1306 + BusIO — OLED-дисплей
       • OneWire + DallasTemperature    — датчик температуры DS18B20
       • AsyncTCP + ESPAsyncWebServer   — веб-интерфейс мозга

═══════════════════════════════════════════════════════════════════════
ПОСЛЕ УСТАНОВКИ — КАК ПРОШИТЬ
═══════════════════════════════════════════════════════════════════════
  1. Откройте Arduino IDE.
  2. Откройте прошивку мозга:  Проект\H2_Brain_v5\H2_Brain_v5.ino
  3. Инструменты → Плата → «ESP32 Dev Module».
  4. Подключите плату USB-кабелем (с передачей данных!), затем
     Инструменты → Порт → выберите появившийся COMx.
  5. Нажмите «Загрузить (→)». Если зависнет на «Connecting…» —
     зажмите кнопку BOOT на плате на пару секунд.
  6. То же повторите для пульта:  Проект\H2_Remote_v5\H2_Remote_v5.ino
     (прошивайте ОБА устройства — протокол общий).

  Веб-интерфейс мозга после включения:
     Wi-Fi сеть:  H2_PRO     пароль:  hydrogen_2024
     Адрес:       http://192.168.4.1
     Вкладка «Диагностика» покажет, какие модули найдены/не найдены.

═══════════════════════════════════════════════════════════════════════
СОДЕРЖИМОЕ ПАПКИ
═══════════════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════════════
ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
═══════════════════════════════════════════════════════════════════════
  • Плата не видна / нет COM-порта:
      Переткните USB-кабель (нужен кабель С ПЕРЕДАЧЕЙ ДАННЫХ, не «только
      зарядка»). Драйвер ставится автоматически; вручную — открыть
      Диспетчер устройств, найти «CP2102 …» с восклицательным знаком,
      Обновить драйвер → указать папку drivers\CP210x.

  • ESP32-ядро не установилось (нет интернета или ошибка):
      В Arduino IDE: Файл → Настройки → «Дополнительные ссылки для
      менеджера плат» → вставьте:
        https://espressif.github.io/arduino-esp32/package_esp32_index.json
      Затем Инструменты → Плата → Менеджер плат → найдите «esp32» →
      Установить. Библиотеки уже установлены офлайн.

  • «Загрузка» зависает на Connecting…:
      Зажмите BOOT при появлении надписи Connecting, отпустите.

  • Схемы сборки и распайки — в папке «Документы»
    (H2_Assembly_Full.html — пошагово, H2_board_pinout.png — фото платы).
